# Header Component

Компонент шапки приложения с названием фирмы слева и профилем пользователя справа.

## Особенности

- ✅ Адаптивный дизайн для мобильных устройств
- ✅ Интеграция с системой аутентификации
- ✅ Полнофункциональный выход из системы
- ✅ Многоуровневое меню настроек
- ✅ Соответствие дизайн-системе Fluent UI
- ✅ TypeScript поддержка

## Использование

```tsx
import { Header } from '@/components/Header';

// Базовое использование с названием по умолчанию
<Header />

// С кастомным названием фирмы
<Header companyName="My Company" />
```

## Настройка

Название фирмы по умолчанию можно изменить в файле `src/config/company.ts`:

```ts
export const COMPANY_CONFIG = {
  name: 'Ваше название фирмы',
  // другие настройки...
};
```

## Функциональность

### Выпадающее меню пользователя содержит:
- **Settings** - подменю с категориями настроек:
  - Organization Settings
  - User Management  
  - Storage Settings
  - Validation Settings
  - Approval Settings
- **Sign out** - полный выход из системы с перенаправлением

### Logout процесс:
1. Очистка токенов аутентификации
2. Обновление состояния приложения  
3. Автоматическое перенаправление на LoginScreen
4. Уведомление о успешном выходе

## Структура

- `Header.tsx` - основной компонент
- `SettingsMenu.tsx` - подменю настроек
- `index.ts` - экспорт компонента
- `README.md` - документация
- `LOGOUT_IMPLEMENTATION.md` - детали реализации выхода

## Зависимости

- `@fluentui/react-components` - UI компоненты
- `@fluentui/react-icons` - иконки
- `@/shared/lib/AppProvider` - контекст пользователя
- `@/entities/user/ui/UserAvatar` - аватар пользователя
