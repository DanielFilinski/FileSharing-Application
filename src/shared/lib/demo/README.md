# 🎭 Demo Mode - Временная система для демонстрации

> ⚠️ **ВНИМАНИЕ**: Этот функционал создан ТОЛЬКО для демонстрации возможностей системы заказчику и разработки. **ОБЯЗАТЕЛЬНО УДАЛИТЬ ПЕРЕД ПРОДАКШНОМ!**

## 🎯 Назначение

Demo Mode временно отключает все ограничения RBAC системы, предоставляя полный доступ ко всем функциям приложения. Это позволяет:

- Демонстрировать все возможности системы заказчику
- Тестировать функционал без настройки сложных ролей
- Разрабатывать новые функции без ограничений доступа

## 🔧 Как это работает

### Активация
- Кнопка "Demo Mode" в навигации (рядом с переключателем темы)
- При включении показывается синий баннер в верхней части интерфейса
- Все `PermissionGate` компоненты пропускают контент
- Все проверки разрешений в RBAC возвращают `true`

### Интеграция с RBAC
```typescript
// В демо-режиме все разрешения предоставляются
const checkPermission = (permission: Permission): PermissionCheck => {
  if (isDemoMode) {
    return {
      granted: true,
      reason: 'Demo Mode - all permissions granted for demonstration'
    };
  }
  // ... обычная логика
};
```

### Компоненты
- `<PermissionGate>` - пропускает весь контент
- `withPermissions()` - не блокирует компоненты
- Все хуки разрешений возвращают `true`

## 🚀 Использование во время разработки

```tsx
import { useDemoMode } from '@/shared/lib/demo';

const MyComponent = () => {
  const { isDemoMode, toggleDemoMode } = useDemoMode();
  
  return (
    <div>
      {isDemoMode && <span>🎭 Demo режим активен</span>}
      <button onClick={toggleDemoMode}>Toggle Demo</button>
    </div>
  );
};
```

## 📊 Визуальные индикаторы

### Кнопка в навигации
- **Выключен**: Серая кнопка "Demo Mode" с иконкой Play
- **Включен**: Синяя кнопка "Demo ON" с иконкой Stop, подсвечена

### Баннер
- Показывается в верхней части всех страниц при включенном режиме
- Синий цвет с информацией о том, что ограничения отключены
- Кнопка быстрого отключения

## ⚡ Производительность

Demo Mode не влияет на производительность приложения:
- Добавляет только простую проверку `if (isDemoMode)` в критических местах
- Не изменяет структуру данных или API вызовы
- Локальное состояние в React контексте

## 🔒 Безопасность

- **НЕ** отправляет никаких данных на сервер о статусе демо-режима
- **НЕ** изменяет реальные разрешения пользователя в базе данных
- Работает только на фронтенде для UI демонстрации
- Backend проверки остаются активными (если реализованы)
